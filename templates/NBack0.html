Instructions

Now we will describe the first task you will perform.

  • You will be playing a number memory game where a series of numbers will be presented to you one by one .
  • For each new number presented, your task is to type in the number. For example, if you see number 6 and asked to enter the number, you need to type 6. The next number will be displayed only after you respond.
  • The numbers are coloured and will help you distinguish between the repeating numbers. If the numbers are repeated in any case, their colours will change to indicate the change in stimuli.
  • You need to respond by typing the number(0-9) using the number keys on a computer keyboard denoting the number. Please do not use the right-hand side numpad if you are using a standard computer keyboard.
  • The numbers will be only presented visually.
  • The correctness of your response will be visible during the experiment. Correct response will be highlighted with green and incorrect response will be highlighted with red.
